The CPU Performance Equation

CPU Execution Time = Instruction Count × CPIClock Rate
T = (I × CPI) / f
I

Instruction Count

Total number of instructions executed by a program. Determined by the algorithm, source code, compiler, and Instruction Set Architecture (ISA).

CPI

Cycles Per Instruction

Average clock cycles required per instruction. Depends on CPU microarchitecture, pipeline design, cache hierarchy, and instruction mix.

f

Clock Rate

Processor frequency in cycles per second (Hz). Determined by semiconductor technology, transistor design, and CPU voltage/cooling constraints.
